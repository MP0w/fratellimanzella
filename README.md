# Fratelli Manzella

Static site pronta per GitHub Pages.

## Contenuto

- `index.html`: homepage principale
- `styles.css`: stile del sito
- `404.html`: pagina di errore
- `robots.txt` e `sitemap.xml`: file SEO
- `CNAME` e `.nojekyll`: supporto GitHub Pages

## Pubblicazione

1. Crea un repository GitHub dedicato.
2. Pubblica questi file nella root del repository.
3. In `Settings > Pages`, imposta la pubblicazione da `main` sulla root.
4. Mantieni `fratellimanzella.it` come custom domain del progetto.
